1. Install on a new laptop (one time)

Needs Windows 10/11, 8 GB free RAM, about 12 GB free disk and internet. The first start downloads about 4 GB.

StepCommand
1. Install Docker Desktop (runs all services)winget install --id Docker.DockerDesktop
Restart if asked, open Docker Desktop, wait for "Engine running".
2. Install uv (runs the helper scripts, brings its own Python)winget install --id astral-sh.uv
Close PowerShell and open a new window afterwards.
3. Check both toolsdocker --version
uv --version
4. Go to the unzipped project foldercd C:\lead-intel
5. Remove the old laptop's Python environmentRemove-Item -Recurse -Force .venv -ErrorAction SilentlyContinue
6. Install the Python librariesuv sync
7. Check the copy (must end with READY)uv run python scripts/setup_new_machine.py
8. Create the database storagedocker volume create lead-intel-pgdata
9. Start only the database (wait 20 s)docker compose up -d postgres
10. Load the existing leads from the backupuv run python scripts/setup_new_machine.py --load-data backups\lead_intel_20261013T095504Z.dump
Use the newest file in the backups folder. Refuses to overwrite a database that already has data.
11. Build and start everything (10-25 min first time)docker compose up -d --build
12. Health check (last line: SMOKE CHECK PASSED)uv run python scripts/smoke_check.py
13. Check the API keysuv run python scripts/keys.py list
14. Switch the Run button onuv run python scripts/live_mode.py on

3. Live mode: switch the Run button on and off

Safe mode = nothing can spend credits or write to the Google Sheet (default after every start). Live mode = real searches, real credits.

I want toCommand
Switch Run on (live)uv run python scripts/live_mode.py on
Switch Run off (safe)uv run python scripts/live_mode.py off
Which mode is running?uv run python scripts/live_mode.py status

After switching, click Refresh on the dashboard. The chip at the top shows LIVE (green) or SAFE (orange). .env is never changed by this command.

5. Find leads

From the dashboard (recommended)

  1. Live mode on (section 3), dashboard refreshed.
  2. Find new leads: type what you look for - a sentence (for example healthtech startups that raised funding recently) or search words, one search per line. Empty = saved default searches.
  3. Pick the Lead owner, set Leads wanted (1-10) and Companies checked per round (25 recommended), click Run.
  4. One round takes about 4-5 minutes; the run repeats rounds (at most 5) until it has the wanted leads. Do not click Run twice - the page follows the running run.
  5. Results: summary under the Run button, new rows in the Google Sheet tab "Ai Leads", the Leads table, and "Credits used by this run".

From PowerShell (same pipeline, scriptable)

I want toCommand
Practice run on sample data (no keys, no cost)uv run python scripts/run_pipeline.py
Plan on real data, write nothinguv run python scripts/run_pipeline.py --db --stages all --limit 10
Real run with a prompt and an owner (live mode must be on for this process)$env:PROVIDER_MODE="live"; $env:ALLOW_PAID_PROVIDER_CALLS="true"; $env:ALLOW_SHEETS_WRITES="true"
uv run python scripts/run_pipeline.py --db --live --stages all --limit 15 --owner Meera --prompt "startup raises Rs 2 crore seed funding;healthtech startup raises pre-seed"
Remove-Item Env:PROVIDER_MODE; Remove-Item Env:ALLOW_PAID_PROVIDER_CALLS; Remove-Item Env:ALLOW_SHEETS_WRITES
Only AI analysis + sheet for waiting leads(same three env lines) uv run python scripts/run_pipeline.py --db --live --stages analysis,export --limit 10
List recent runsuv run python scripts/run_pipeline.py --db --status
Free a stuck run ("already in progress")uv run python scripts/run_pipeline.py --db --recover

Stages in order: discovery, prescreen, website, signals, qualification, enrichment, analysis, export (--stages all = all eight).

6. API keys: add, check, remove

Several keys per provider are supported for Apify, Firecrawl, Hunter and Apollo: the first is used, the others are backups that take over automatically when a key is refused or out of credits. Claude and OpenAI have one key each.

I want toCommand
See every key: accepted?, used, date credits come backuv run python scripts/keys.py list
Add an Apify key (backup)uv run python scripts/keys.py add apify
Add a Firecrawl keyuv run python scripts/keys.py add firecrawl
Add a Hunter keyuv run python scripts/keys.py add hunter
Add an Apollo keyuv run python scripts/keys.py add apollo
Replace the Claude keyuv run python scripts/keys.py add claude
Remove a dead key (number from list)uv run python scripts/keys.py remove firecrawl 2
Save a key the provider refuses anyway (rare)uv run python scripts/keys.py add apify --force
Check the Claude key from inside the app (free)docker compose exec -T app python -c "import asyncio; from app.core.config import Settings; from app.providers.anthropic import AnthropicAdapter; print(asyncio.run(AnthropicAdapter(Settings()).check_model()))"
How "add" works: paste the key at the hidden prompt (right-click or Ctrl+V, then Enter). Extra spaces, quotes, Bearer or NAME= are removed. The key is checked with the provider's free account endpoint; a refused key is not saved. The app is then restarted in the same mode so the key is used at once. A used-up key is tried again every 6 hours, so it comes back by itself when the provider's new month starts.

9. Share the dashboard with others (link)

StepCommand
1. Install Cloudflare's tunnel tool (once)winget install --id Cloudflare.cloudflared
Then open a NEW PowerShell window.
2. App running (live if others should Run)docker compose up -d · uv run python scripts/live_mode.py on
3. Start the tunnel (keep this window open)cloudflared tunnel --url http://127.0.0.1:8000
4. ShareSend the printed https://....trycloudflare.com address with /dashboard at the end, plus the token (copy it with uv run python scripts/copy_operator_token.py) through a private channel.
5. Stop sharingPress Ctrl+C in the tunnel window. The link stops working at once.

The link changes every time the tunnel starts. The laptop, Docker and the tunnel window must stay on while others use it.

13. Hand the project to another laptop (zip)

  1. Make a fresh backup: uv run python scripts/backup_db.py
  2. Stop the app: docker compose stop
  3. Zip the project folder. Include .env, secrets\google\service-account.json, backups\ and sidecars\. Leave out .venv (198 MB, rebuilt on the new laptop) and .git.
  4. Send the zip privately (it contains every key). On the new laptop follow section 1.
Both laptops then share the same API keys and Google Sheet but have separate databases. Agree that one laptop does the live runs, or give the second laptop its own sheet ID in its .env.
