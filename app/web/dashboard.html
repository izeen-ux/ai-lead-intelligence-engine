Unlock the dashboard

The data is protected by an operator token so nobody else on the network can read your leads. You enter it once; this browser remembers it.

  1. In PowerShell, in the project folder, run: uv run python scripts/copy_operator_token.py - it copies the token to the clipboard (nothing is shown on screen).
  2. Click the box below, press Ctrl+V, then Unlock.
How it works 8 steps from a search to a row in the Google Sheet

It finds young Indian companies that just raised a small round or are visibly growing, checks each one against fixed qualification rules, finds a verified decision-maker contact, and writes an evidence-based AI outreach angle. Every value links back to the public source it came from; nothing is guessed.

1 Discovernews, LinkedIn, X, Reddit→ 2 Pre-screenfree check before paid scraping→ 3 Verify websiteofficial site + pages→ 4 Signalsfunding, hiring, launches→ 5 QualifyIndia · round ≤ ₹5 Cr or recent intent→ 6 Enrichverified founder email→ 7 AI analysisoffer + outreach hook→ 8 Google Sheettab “Ai Leads”

Find new leads

Say what you are looking for (for example healthtech startups that raised funding recently) or write your own search words, one search per line. Empty = the saved default searches. Set Leads wanted: the run keeps searching in rounds until it has that many new leads or runs out of rounds. One round takes about 5-10 minutes. New leads go to the Google Sheet tab Ai Leads and the Leads table below.

Run is switched OFF (safe mode). Nothing can spend credits right now, so the Run button will not start anything. To switch it on, run this in PowerShell in the project folder, wait until it finishes, then click Refresh at the top of this page:
uv run python scripts/live_mode.py on
Switch it off again afterwards with uv run python scripts/live_mode.py off.
